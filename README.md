# Riverbend Accessibility Lab

A hands-on project: audit and fix an inherited WordPress site, one step at a time, without rebuilding it.


| Folder | What's inside |
|---|---|
| [legacy-site/](legacy-site/) | The "inherited" WordPress site (Docker, runs locally): Astra, Elementor, Beaver Builder, Contact Form 7, with 13 planted accessibility barriers |
| [audit-lab/](audit-lab/) | The step-by-step lab guide, plus evidence: findings log, scorecard, journal and screenshots |

Standard: WCAG 2.1 AA, plus the new WCAG 2.2 criteria.
